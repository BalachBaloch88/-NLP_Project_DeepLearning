# Urdu ⇄ English Translator

Streamlit app for Urdu / English / Hindi translation using `deep-translator`.

## Run locally
    pip install -r requirements.txt
    streamlit run app.py

## Deploy
1. Upload all files to a GitHub repo (app.py and requirements.txt in the repo root).
2. Go to https://share.streamlit.io -> Create app -> choose repo, branch main, file app.py -> Deploy.
